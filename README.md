# Exoplanet-Discovery-Assistant

*An AI-powered web application that analyzes stellar light curves to identify and validate exoplanet transits.*

## What It Does

The Exoplanet Discovery Assistant processes light curve data to determine if brightness dips indicate a true exoplanet discovery. Users can test preloaded sample data or upload custom files. The app delivers instant classification predictions, a dynamic confidence probability bar, and transparent step-by-step explanations detailing the physical evidence behind the findings.

## Tech Stack

* **Backend & ML:** Python, NumPy, Pandas, Scikit-Learn / Keras
* **Frontend:** Streamlit / Gradio (Clean Dark Theme)
